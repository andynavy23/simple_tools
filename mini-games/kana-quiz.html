練習結束

點任何一格會念出該假名（需要裝置有日文語音，沒有就不會出聲）。每格由上到下：平假名、片假名、羅馬拼音。

小提醒

  • 促音 っ / ッ：小的「つ」，不發音、只停頓一拍，並讓後面的子音重複。きって → kitte、ざっし → zasshi。
  • 撥音 ん / ン：獨立一拍的鼻音，羅馬拼音寫 n（也常寫 nn 或 n'，例如 しんい shin'i）。
  • 拗音：「い段」假名 + 小的 ゃ ゅ ょ 合成一拍，例如 き + ゃ = きゃ kya；注意 ちゃ 與 ちや 不同。
  • 長音：あ段加あ、い段加い、う段加う、え段加え / い、お段加お / う 會拉長一拍，片假名則用「ー」。
  • 助詞：は 當助詞念 wa、へ 念 e、を 念 o。
  • じ / ぢ、ず / づ：發音相同，ぢ、づ 很少用（例如 はなぢ、こづつみ）。練習時 ぢ 接受 ji / di / zi，づ 接受 zu / du。
