這個裝置無法分享螢幕

手機瀏覽器（iPhone Safari、Android Chrome）都沒有開放「擷取螢幕」功能，網頁做不到。請改用電腦的 Chrome / Edge / Firefox / Safari 來分享；這支手機可以當觀看端。

想把手機畫面鏡像到電腦，請看下方「手機螢幕鏡像到電腦怎麼做」。

手機螢幕鏡像到電腦怎麼做

為什麼本頁做不到？瀏覽器沒有開放「擷取手機自己的螢幕」給網頁（手機版瀏覽器不支援 getDisplayMedia）。要鏡像手機畫面，只能靠作業系統或原生 App 的功能：

Android → 電腦：scrcpy（開源，Windows / Mac / Linux）

  • 手機：設定 → 關於手機，連點「版本號碼」開啟開發人員選項，再開啟「USB 偵錯」（選單名稱依廠牌略有不同）。
  • 用 USB 線接電腦，手機跳出「允許 USB 偵錯」時按允許。
  • 電腦安裝 scrcpy，到官方 GitHub（Genymobile/scrcpy）下載，或用套件管理員：
winget install scrcpy      # Windows
brew install scrcpy        # macOS
sudo apt install scrcpy    # Debian / Ubuntu（版本可能較舊）
  • 執行 scrcpy 即可看到並操作手機。常用：scrcpy --record out.mp4 錄影、scrcpy --no-audio 不傳聲音。
  • 無線：Android 11 以上可在開發人員選項開「無線偵錯」，依畫面用 adb pair、adb connect 連上後再執行 scrcpy（需同一個 Wi-Fi）。

Windows 內建方式

  • 「手機連結」App（Phone Link）：部分 Android 機型支援在電腦上看到手機畫面；iPhone 目前只有通知、訊息、通話等部分功能，不是螢幕鏡像。支援機型以 Microsoft 與手機廠商的官方說明為準。
  • Miracast：Windows 設定 → 系統 → 投影到這部電腦（可能要先在「選用功能」安裝「無線顯示器」）。手機端的名稱依廠牌而異，常見「智慧鏡像 / Smart View / 投射 / 螢幕鏡像」。支援度與延遲因裝置而異。

iPhone → Mac

  • 較新的 macOS / iOS 內建「iPhone 鏡像輸出」，可在 Mac 上看到並操作 iPhone（需符合系統與帳號條件，細節見 Apple 官方說明）。
  • USB 錄影：用傳輸線接 Mac，開 QuickTime Player → 檔案 → 新增影片錄製，相機選你的 iPhone。
  • AirPlay：新版 macOS 可以把 Mac 當 AirPlay 接收端（在系統設定的 AirDrop 與 Handoff / 一般 附近尋找「AirPlay 接收器」，路徑依版本略有不同）；iPhone 控制中心 → 螢幕鏡像 → 選那台 Mac。

iPhone → Windows

Windows 沒有內建 AirPlay 接收端，需要第三方「AirPlay 接收器」類桌面軟體（有免費與付費版）。風險：要放行防火牆與區域網路連線、需信任軟體來源；請只從官方網站下載、避免破解版，用完可關閉或移除；兩台要在同一個網路。

Chromecast / Google Home

Android 可用 Google Home App 的「投放螢幕」把畫面送到 Chromecast 或支援的電視（不是送到電腦）。iPhone 無法用它鏡像整個畫面；部分 App 內的投放鈕只會投該 App 的影片。
