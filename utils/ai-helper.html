AI 開發小幫手

做 AI 應用時常用的小計算：估 token、算費用、產生 function calling 的 schema、整理 Prompt 範本、比對向量。全在本機運算。

Token 數量估算

這是粗略近似：英文約 4 個字元 ≈ 1 token，中日韓文字約 1–1.5 個字元 ≈ 1 token。實際數字依模型的 tokenizer 而異，誤差可能達 ±30% 以上，程式碼、emoji、罕見字更不準。要精確請用該模型的官方計數工具，或以 API 回傳的 usage 為準。

模型費用計算

本工具不內建任何模型價格（價格常調整）。請到該服務的官方定價頁，把「每百萬 token」的單價抄進來。

上下文長度速查

這張表由你自己填：各模型的上下文長度會隨版本改變，這裡不內建數字。請從官方文件抄最新數值（單位：token），資料存在這台裝置的瀏覽器。

向量相似度

教學用：餘弦相似度看「方向」（1 同向、0 垂直、−1 反向），不受長度影響，是文字嵌入最常用的比較方式；歐氏距離看「點與點的距離」；內積同時受方向與長度影響，向量都已正規化（長度 1）時內積就等於餘弦相似度。
