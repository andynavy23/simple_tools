JSON 整理器

貼上 JSON，一鍵美化、壓縮或驗證，也能和 YAML、TOML、CSV 互轉。全部在本機處理。

格式轉換

把上方輸入的內容轉成別種格式（結果顯示在下方）。YAML、TOML 支援常用語法；CSV 需要第一列是標題。

產生型別

把上方輸入的 JSON 當範例，推論欄位型別並產生程式碼。陣列有多筆時會合併所有元素的欄位（沒出現在每一筆的欄位視為可選）。

查詢（JSONPath / jq）

對上方輸入的 JSON 下查詢，結果顯示在下方。$ 開頭是 JSONPath，其他是 jq 子集。不支援的語法會明確報錯。

鍵整理與欄位選取

把上方輸入的 JSON 整理成方便比對（diff）的樣子，或只留下需要的欄位、批次改名。

設定檔 ⇄ JSON（INI / .properties / .env）

把上方輸入的內容在設定檔格式與 JSON 之間轉換；不支援或有疑慮的地方會列在結果上方的提醒。

i18n 翻譯檔互轉（JSON ⇄ PO ⇄ CSV）

上方輸入當「主要檔」。要檢查缺漏鍵時，把另一個語言的檔案貼在下面的「對照檔」（和主要檔同一種格式）。巢狀 JSON 用「.」連成鍵名。
